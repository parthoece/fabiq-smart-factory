# v1.0.0 — Initial Public Release

## Release Summary

This is the first public portfolio release of the **Fabiq Smart Factory MES Integration Platform**.

Fabiq is a production-inspired smart manufacturing platform that demonstrates how modern MES and Industrial IoT systems can ingest, process, persist, and visualize manufacturing events using an event-driven architecture.

---

## Highlights

- Event-driven smart factory architecture
- Apache Kafka manufacturing event backbone
- ASP.NET Core backend API
- PostgreSQL persistence
- React dashboard
- Machine simulator
- AI anomaly detection worker
- Maintenance alert pipeline
- OEE, downtime, production, and traceability features
- Docker Compose orchestration
- Prometheus and Grafana observability
- Comprehensive technical documentation

---

## Core Capabilities

### Manufacturing

- Machine status tracking
- Work order management
- Production event processing
- Downtime tracking
- OEE calculation
- Part traceability
- Maintenance alerts

### Event Streaming

- Kafka-based asynchronous event flow
- Automatic topic initialization
- Manufacturing event topics:
  - `machine.status`
  - `production.counts`
  - `downtime.events`
  - `machine.telemetry`
  - `maintenance.alerts`

### AI / Anomaly Detection

- Independent anomaly detection worker
- Telemetry processing
- Rule-based anomaly detection
- Maintenance alert generation

### Observability

- Health endpoint
- Readiness endpoint
- Prometheus metrics endpoint
- Grafana dashboard support

### Developer Experience

- Docker Compose local environment
- PowerShell helper scripts
- Swagger / OpenAPI documentation
- Structured technical documentation

## Recommended Demo Flow

1. Start the platform with Docker Compose.
2. Open the React dashboard.
3. Show machine status, production, OEE, downtime, and traceability.
4. Open Kafka UI and demonstrate manufacturing event topics.
5. Open Swagger and show REST API groups.
6. Open Prometheus and Grafana.
7. Explain the AI anomaly detection pipeline.

---

## Known Limitations

This release is intentionally positioned as a production-inspired portfolio platform rather than a commercial MES product.

Known limitations include:

- No authentication or RBAC yet
- No production PLC / OPC UA integration yet
- No Kubernetes deployment yet
- No centralized logging stack yet
- AI anomaly detection is currently rule-based
- Telemetry storage is designed for demonstration rather than high-volume time-series workloads
