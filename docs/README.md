# Fabiq Documentation

Welcome to the documentation hub for the **Fabiq Smart Factory MES Integration Platform**.

Fabiq is a production-inspired smart manufacturing platform demonstrating MES, IIoT, event-driven backend engineering, Kafka integration, PostgreSQL persistence, React dashboards, AI anomaly detection, and observability.

## Notes

This project is not positioned as a commercial MES replacement. It is a production-inspired engineering platform designed to demonstrate architecture, integration patterns, observability, traceability, and smart manufacturing concepts.
