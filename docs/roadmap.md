# Project Roadmap

## Vision

Fabiq Smart Factory MES Integration Platform is a production-inspired smart manufacturing platform that demonstrates modern Manufacturing Execution System (MES), Industrial IoT (IIoT), and event-driven backend engineering concepts.

The roadmap reflects the evolution from a local demonstration platform toward a more production-oriented architecture while maintaining the project's focus on education, experimentation, and portfolio value.
